# Cyber-Bot FTP Pentest Lab

لاب FTP تدريبي يحتوي على إعدادات ضعيفة **عمداً**: دخول مجهول للقراءة، حساب بكلمة مرور ضعيفة، وأرشيف ZIP مشفر بكلمة مرور ضعيفة. الهدف جمع أجزاء الـ Flag من الخدمة باستخدام Kali Linux.

> **تنبيه:** هذا المستودع يحتوي على مصدر اللاب لأغراض التدريب، وليس خدمة مستضافة. شغّله فقط على جهازك أو شبكة خاصة تملكها. لا تفتح منافذ اللاب للإنترنت ولا تختبر أي جهاز بدون إذن.

## التشغيل الأسهل: Docker

على جهاز اللاب، ثبّت Docker Engine و Docker Compose ثم:

```bash
cp .env.example .env
docker compose up --build
```

الإعداد الافتراضي آمن نسبياً: المنافذ مربوطة على `127.0.0.1`، لذلك لا يستطيع الاتصال إلا الجهاز الذي يشغّل Docker. لوحة المعلومات على `http://127.0.0.1:8080`، وFTP على المنفذ `2121`.

للإيقاف:

```bash
docker compose down
```

## الاتصال من Kali Linux

### Kali واللاب على نفس النظام

إذا شغّلت Docker داخل Kali نفسها، استخدم عنوان loopback:

```bash
nmap -sV -p 2121 127.0.0.1
ftp 127.0.0.1 2121
```

### Kali VM منفصلة عن جهاز اللاب

`127.0.0.1` داخل Kali يشير إلى Kali نفسها، وليس إلى جهاز اللاب. استخدم شبكة **Host-only** أو **Bridged** بين الجهازين، ثم على جهاز اللاب اعرف عنوانه الخاص:

```bash
ip -4 -brief address
```

اختر عنوان واجهة الشبكة التي تستطيع Kali الوصول إليها، وليس عنوان `docker0`. انسخ `.env.example` إلى `.env` وعدّل القيم التالية إلى عنوان جهاز اللاب الخاص، مثلاً `192.168.56.1`:

```dotenv
LAB_BIND_ADDRESS=192.168.56.1
LAB_ADVERTISE_ADDRESS=192.168.56.1
```

أعد تشغيل اللاب:

```bash
docker compose up --build
```

اسمح من جدار الحماية باتصالات TCP من عنوان Kali فقط إلى `2121` ومنافذ FTP السلبية `6000-6009`؛ منفذ لوحة المعلومات `8080` اختياري. استخدم العنوان الخاص نفسه كـ `TARGET_IP` في الأوامر. لا تستخدم `0.0.0.0` أو تحويل منافذ الراوتر كعنوان هدف، ولا تعرّض الخدمة للإنترنت.

## خطوات التحدي

ابدأ بفحص خدمة FTP والدخول المجهول، ثم اقرأ التلميحات الموجودة عبر FTP. بعد ذلك اختبر كلمة مرور الحساب الضعيفة باستخدام قائمة كلمات محلية، نزّل `backup.zip` وحاول كسر كلمة مروره محلياً، ثم اجمع أجزاء الـ Flag.

أمثلة أوامر من Kali (استبدل `TARGET_IP` بعنوان جهاز اللاب الخاص):

```bash
nmap -sV -p 2121 TARGET_IP
ftp TARGET_IP 2121
hydra -l ftpuser -P /path/to/wordlist.txt -s 2121 -f ftp://TARGET_IP
fcrackzip -u -D -p /path/to/wordlist.txt backup.zip
```

يمكن استخدام `john` مع `zip2john` بدلاً من `fcrackzip`. لا تشغّل أدوات التخمين إلا على هذا اللاب أو على هدف لديك إذن صريح لاختباره.

## تشغيل مباشر بدون Docker

Python 3.9+ مطلوب. يفضّل تثبيت الاعتماديات داخل بيئة افتراضية:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 ftp_lab.py
```

افتراضياً يستمع FTP وواجهة الويب على loopback فقط. للتشغيل المباشر من VM ثانية، اربطه بعنوان خاص محدد (عدّل العنوان حسب شبكتك)، مثلاً:

```bash
python3 ftp_lab.py --host 192.168.56.1 --port 2121 --http-port 8080 --advertise-address 192.168.56.1
```

افتح منافذ FTP السلبية `6000-6009` في الجدار الناري للـ VM المصرّح لها فقط. لا تربطه بواجهة عامة.

## حدود الاستضافة

رفع الكود إلى GitHub لا يشغّل FTP ولا ينشئ لك IP لخادم. شغّل اللاب على جهازك أولاً؛ عنوان الهدف هو عنوان ذلك الجهاز الخاص القابل للوصول من Kali، والمنفذ الافتراضي هو `2121`. لا أستطيع توفير عنوان عام مستضاف من هذا المستودع.
